## A local workspace around the globe

Geospatial Intelligence Hub brings reference material and navigation alongside God's Eye View (GEV). The globe remains the existing vanilla JavaScript/Cesium application at `/`; the React hub lives at `/hub/` on the same localhost server. The hub does not embed or replace the globe.

This guide describes the reviewed upstream revision `064d51f7be2675f1c69e16068e9c49d1a60144d1`. GEV's own account of the project's purpose is available in the [pinned README](https://github.com/bilawalsidhu/gods-eye-view/blob/064d51f7be2675f1c69e16068e9c49d1a60144d1/README.md#-why-this-exists). Treat that account as upstream context; the features available in this checkout are established by its current code, source records and validation evidence.

## What the Library adds

The Library organizes three kinds of reference material: source and product records, selected upstream documentation, and original explanatory articles. Its records describe coverage, access requirements and evidence. A review date says when documentation was checked; it is not a feed timestamp.

The directory labels its facts **Static** and its feed health **Not checked in Library**. Opening an article or searching local reference text does not establish that a provider is reachable or that a displayed observation is current. Operational status still belongs to the existing globe and its source owners.

Phase 2b remains deferred. Acquisition ownership changes, passive dashboard summaries and an upcoming-launch query are not delivered by these reference pages. Recording, hosting and new source integrations also require their own review and approval.

## Use the existing handoff

Open the globe from the hub when you want to explore. The existing share-link handoff preserves an accepted complete version 2 URL rather than rebuilding it from a smaller camera-only view. A valid link describes supported view state; it does not by itself prove that a historical event, Director scene, mission or replay is restored.

Keep provider credits visible. An available layer can combine observations, estimates and bundled reference material, so evaluate the particular value and its provenance rather than treating the whole screen as live intelligence. GEV's [data-source documentation](https://github.com/bilawalsidhu/gods-eye-view/blob/064d51f7be2675f1c69e16068e9c49d1a60144d1/DATA_SOURCES.md) separates runtime sources from bundled snapshots.

GEV's [MIT license](https://github.com/bilawalsidhu/gods-eye-view/blob/064d51f7be2675f1c69e16068e9c49d1a60144d1/LICENSE) governs the code and covered documentation. It is not blanket permission to reuse every image, dataset, recording or provider response. Preserve the [third-party notices](https://github.com/bilawalsidhu/gods-eye-view/blob/064d51f7be2675f1c69e16068e9c49d1a60144d1/THIRD_PARTY_NOTICES.md) and inspect source-specific restrictions before reusing material.

The current project scope is local personal use. Public availability of a source is not approval for archiving, redistribution or hosting. The globe is an exploration and learning tool; its [responsible-use guidance](https://github.com/bilawalsidhu/gods-eye-view/blob/064d51f7be2675f1c69e16068e9c49d1a60144d1/SECURITY.md#responsible-use) does not promise complete or operationally reliable observations.
